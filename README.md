# CampusFix — Smart Campus Problem Reporting System

A front-end prototype for a CODESTROAM 2026 project idea.

## Features
- Submit a campus maintenance issue with title, category, priority, location, and description.
- View recent reports and search/filter them.
- Update report status: Submitted, In Progress, Resolved.
- Delete reports and clear demo data.
- Responsive layout for desktop and mobile.
- Reports are saved in the browser's localStorage on the current device.

## Technology
- HTML
- CSS
- Vanilla JavaScript

## Run locally
1. Download or extract this folder.
2. Open `index.html` in a modern web browser.
3. Submit a sample issue to test the interface.

No build tools or server are required.

## Important limitations
This is a prototype, not a production campus system. Data is stored only in the current browser and is not shared with other users or devices. There is no real login, cloud database, notification service, or verified campus maintenance workflow yet. Do not enter private or sensitive information.

## Suggested future improvements
- Add Firebase authentication and database.
- Add role-based access for students and maintenance administrators.
- Add image uploads and notifications.
- Test usability with students and campus staff.
